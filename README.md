## Dataset Links and Descriptions

### Sriram's Dataset
Pitt email: sas547@pitt.edu
https://data.wprdc.org/dataset/allegheny-county-crash-data
This dataset included all of the police reports regarding crashes within Allegheny county in the year 2025.

https://data.wprdc.org/dataset/neighborhoods2
This dataset is a GeoJson file focused on the neighborhoods of Pittsburgh, that I used to separate my original dataset into neighborhoods.

This repository analyzes the data provided from the crash report dataset by separating each report based on neighborhood using the Latitude and Longitude data from the crash reports in tandem with the Pittsburgh neighborhoods GeoJson file. I then counted the number of incidents per neighborhood, separated by fatality, injury, and no injury / fatality. Then displayed this data using stacked bar graphs based on neighborhoods.

### Connor Readinger's Dataset
Pitt email: cjr213@pitt.edu
https://data.wprdc.org/dataset/pittsburgh-311-data/resource/5202679a-d243-402e-b82a-63189995a942
This dataset tracks the roadwork requests by area, allowing for the determination of average road quality by the number of requests per neighborhood.

This repository uses the data from the provided dataset to rank each respective Pittsburgh neighborhood by the amound of roadwork requests that occur within each neighborhood, as more roadwork requests implies to worsened driver experience due to lower road quality.

### Weston Johnson's Dataset

https://data.wprdc.org/dataset/right-of-way-permits/resource/cc17ee69-b4c8-4b0c-8059-23af341c9214
